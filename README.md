# TradeLog · 交易计划

基于 Node.js、Vue 3、TypeScript 和 Element Plus 的本地交易计划应用。记录交易分析、入场和出场理由、计划价位及行情截图，数据保存在本机。

## 启动

需要 **Node.js 22.13.0 或更高版本**，使用 Node.js 内置 SQLite，无需另装数据库。在项目根目录运行：

```powershell
npm install
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。开发命令同时启动 Vite 和端口 3001 的 API。前端端口被占用时以终端显示地址为准，启动前停止本项目已有服务，避免端口冲突。

构建后运行：

```powershell
npm run build
npm start
```

打开 [http://127.0.0.1:3001](http://127.0.0.1:3001)。前端和 API 由同一 Node.js 服务提供，仅监听本机 127.0.0.1。前端修改后重新构建，后端修改后重启服务，Ctrl+C 停止。Node.js 22 可能显示 SQLite ExperimentalWarning。

## 记录计划

新建计划，填写品种、方向、分析周期、市场状态、关键结构、入场理由和出场理由。品种默认 XAUUSD，支持搜索及自定义代码；选择候选或按 Enter 确认输入。出场理由最多 500 字，可留空。

行情截图支持上传或直接粘贴 PNG、JPEG、WEBP，每份计划最多 4 张，每张不超过 5 MB。截图随计划保存，点击可预览，编辑时可移除。

计划入场价、止损价和止盈价由手动填写，均可留空。已填价格须为正数，并符合做多 / 做空的价位关系。三项完整时显示按价格距离计算的收益 / 风险倍数（R），不含交易成本。

新建计划时直接显示表单，不显示页签。计划保存后，查看和编辑页面按“交易计划 / 关联订单 / 计划事件 / 计划复盘”显示四个页签；后三个页签目前为空白。切换页签保留正在编辑的计划。返回列表或通过导航离开前会确认未保存内容，刷新或关闭页面由浏览器提示。保存期间暂时不能切换。

## 状态与排序

计划状态包括草稿、待触发、已执行、未触发、取消、失效。点击列表或详情的状态标签手动选择；待触发和已执行需要完整的品种、方向、分析周期及入场理由，出场理由和价位仍可留空。

编辑正文保留当前状态；实际变更状态时记录变更时间。取消原因可选填，改回其他状态后保留上次原因。已有 executed 状态直接显示为“已执行”。

列表默认最新创建优先，点击“创建时间”可切换最早优先；排序作用于全部计划并回到第一页。编辑不会改变创建时间。右上角月亮 / 太阳切换日夜主题，偏好保存在当前浏览器，截图保持原图。

## 导出与备份

“导出数据”下载 `交易计划.zip`，包含 `交易计划.md` 和 `images/`。导出全部已保存计划的当前字段、状态与原始截图，不受分页影响，不包含未保存输入。解压整个 ZIP 并保留图片目录结构即可离线阅读。ZIP 是阅读资料，不能导入恢复数据库。

数据保存在根目录 `data/trading.sqlite`。升级、回退或恢复前，先停止所有使用该库的服务，再备份整个 `data` 文件夹，包括可能存在的 WAL / SHM 文件；不要只复制运行中的主数据库。

功能精简不删除既有数据库表、历史字段或截图。应用仅使用计划与计划图片表；停用功能的数据继续留在原库中，不在当前界面或导出中展示。本次开发未读取、初始化或修改真实数据库。

## 工程说明

前端使用 Vue 3、TypeScript、Element Plus 和 Vite，后端使用 Express 与内置 SQLite，JSZip 用于 Markdown 和图片打包。当前仅记录计划，不连接交易账户或执行交易。

按当前要求不新增或运行测试，不做 API 或浏览器验收。`npm run build` 仅进行 TypeScript 检查与前端构建，不代表运行时行为已验证。真实截图、报告、数据库及凭据不得提交源码仓库。
